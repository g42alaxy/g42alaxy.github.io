# Beautiful Bio for Scientists

> This repo is build upon [Connect – a totally free, no-server bio site for tech folks ✨](https://github.com/mathetos/mathetos.github.io) an open-source pakage distributed under MIT license 

## Structure: 

`config.json` - name, tagline, photo, social links and theme

`info.md` - the Bio (`## Bio`, plain text) and the Recent News list (`## Recent News`, one line per item: `- [Text](https://link)` or `- Text`, newest on top)
